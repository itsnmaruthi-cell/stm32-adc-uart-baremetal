# STM32 Bare-Metal ADC to UART (Potentiometer Reader)

A register-level (no HAL, no DMA) STM32 project that reads a potentiometer through
the ADC and streams the live voltage over UART every 500 ms — built entirely with
direct memory-mapped register access.

## Overview

- **Board:** STM32 Nucleo-64 (F401RE)
- **Input:** Potentiometer wiper connected to PA0 (ADC1, Channel 0)
- **Output:** Voltage reading sent over USART2 (ST-LINK Virtual COM Port) every 500 ms
- **Style:** Bare-metal — every peripheral configured by direct register writes,
  no STM32 HAL/LL calls, no `printf`

## Hardware Setup

| Potentiometer Pin | Connection |
|---|---|
| Pin 1 (left) | GND |
| Pin 2 (middle / wiper) | PA0 (CN7, A0) |
| Pin 3 (right) | 3.3V |

All connections were kept within a single half of the breadboard to avoid
split-rail continuity issues.

## How It Works

1. **ADC1** is configured for single-conversion, polling mode on channel 0 (PA0),
   12-bit resolution, 56-cycle sample time.
2. **TIM2** is configured to generate an update interrupt every 500 ms
   (16 MHz HSI clock, prescaler 15999 → 1 kHz tick, ARR = 499).
3. On each TIM2 interrupt:
   - A new ADC conversion is triggered and polled to completion.
   - The 12-bit result is converted to millivolts using integer math
     (no floating-point formatting needed).
   - The value is formatted into a small text buffer (e.g. `2.145 V`).
   - The USART2 TXE interrupt is enabled to begin transmission.
4. **USART2**, running at 9600 baud, sends the buffer one byte per TXE interrupt,
   then disables the interrupt once the message is fully sent.

## Peripherals Used

| Peripheral | Purpose |
|---|---|
| ADC1 (Channel 0 / PA0) | Reads potentiometer voltage |
| GPIOA | PA0 analog mode, PA2/PA3 alternate function (USART2) |
| USART2 (PA2 TX / PA3 RX) | Sends readings to the ST-LINK Virtual COM Port |
| TIM2 | Generates a periodic 500 ms interrupt to trigger sampling |
| NVIC | Manages TIM2 and USART2 interrupts |

## Build & Flash

1. Open the project in STM32CubeIDE (or your preferred STM32 toolchain).
2. Build the project — no external libraries required beyond the standard
   CMSIS/HAL skeleton generated by CubeMX (only `SystemClock_Config` and
   `HAL_Init` are used from HAL; all peripheral configuration is manual).
3. Flash to the Nucleo board via the onboard ST-LINK.

## Viewing Output

1. Connect to the board's ST-LINK Virtual COM Port using any serial terminal
   (PuTTY, Tera Term, screen, etc.).
2. Settings: **9600 baud, 8 data bits, no parity, 1 stop bit (8N1)**.
3. Turn the potentiometer knob — the voltage reading updates roughly every 500 ms.

## Notes / Design Decisions

- All register addresses were sourced directly from the STM32F401RE reference
  manual (RM0368) and datasheet (DS10086), not from CMSIS header macros, to
  reinforce understanding of the underlying memory-mapped I/O.
- Polling is used only for the ADC conversion wait (kept short and bounded);
  TIM2 and USART2 are fully interrupt-driven.
- No DMA — reading and formatting happen synchronously inside the timer ISR.

## Possible Extensions

- Add DMA for continuous ADC sampling without CPU polling.
- Average multiple ADC samples for a more stable reading.
- Support multiple ADC channels.
